# UmbrellaBot

> AI employees operating inside your business.

## Example Interaction

**You (in #cro channel):**
> "Prep me for a follow-up with this agency."

**CRO agent** pulls context, drafts talking points, and suggests a close.

---

## How It Works Under the Hood

- **Slack** = interface (where you talk and think)
- **Each channel** = a specific AI agent with a job description
- **Each agent** has its own knowledge base (SOPs, strategy, deals, tone, history)
- **Agents can hand work to each other** (CRO → Ops → COS)

---

## What's Live Now

- Slack-connected agents responding in real time
- Agent routing by channel
- Clean separation so agents can scale independently

---

## What's Coming Next (The Real Leverage)

- Channel summaries + decision logs automatically saved
- Execution agents (scheduling, follow-ups, doc creation)
- Gmail + Gemini: email drafting, inbox triage, follow-ups
- LinkedIn: relationship context, post drafting, outbound support
- Calendar + docs: meetings created, agendas + notes auto-saved
- Long-term memory per client, deal, or partner

---

## End State

Umbrella isn't AI assistance.
**It's AI employees operating inside your business.**

Each agent has:
- A **role** (CRO, Ops, COS, Strategy, etc.)
- **Clear responsibilities**
- A **knowledge base** (context, history, SOPs, tone)
- **Authority to execute** and hand work to other agents

They operate like real team members:
- They receive requests
- Make decisions within their scope
- Execute work
- Report outcomes back to you

Instead of hiring headcount for every function,
you spin up agents that work 24/7, never forget context, and compound over time.
